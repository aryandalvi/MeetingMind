# Samples

| File | What it is |
|---|---|
| [sample_transcript.txt](sample_transcript.txt) | Input: a 4-person product launch meeting (658 words, timestamps, header metadata). This is also the "Try the sample transcript" text in the app. |
| [sample_output.md](sample_output.md) | Markdown report produced by MeetingMind for this transcript (abstractive mode, meeting date 2026-03-04) |
| [sample_output.json](sample_output.json) | The complete `AnalysisReport` JSON returned by the API |
| [sample_action_items.csv](sample_action_items.csv) | CSV export of the action items |
| [sample_minutes.pdf](sample_minutes.pdf) | PDF meeting minutes export |

These files are real, unedited outputs generated by the backend pipeline. They include its imperfections: for example, the first executive-summary sentence is marked *weakly supported* because the model conflated two facts, and "Ping their team lead" is a sub-step that a human might merge into the legal follow-up.
